### 🚀 Featured Projects

#### 1. [Financial Distress Prediction System (IDX Manufacturing)](https://github.com/Wahyu2607/financial-distress-app)
An interactive Streamlit decision support application that predicts financial distress in Indonesia Stock Exchange (IDX) manufacturing companies.
* **Key Highlights:** Compares **Extreme Gradient Boosting (XGBoost)** trained directly on raw financial features against **Altman Z''-Score** and re-estimated Multiple Discriminant Analysis (MDA) models.
* **Tech Stack:** `Python`, `Streamlit`, `XGBoost`, `Scikit-learn`, `Pandas`, `Plotly`

#### 2. Educational Facility Classification & Need Prediction (Banten Province)
A spatial and demographic analytics dashboard designed to evaluate school capacity gaps and classify educational facility needs across Banten.
* **Key Highlights:** Integrates **K-Means Clustering**, **Support Vector Machine (SVM)** classification, and **SHAP** (Model-Agnostic Interpretation) for transparent feature-level insights.
* **Tech Stack:** `Python`, `Streamlit`, `Scikit-learn`, `SHAP`, `NumPy`, `Plotly`

#### 3. Indonesian Traditional Food Image Classification Benchmark
A comparative computer vision study evaluating traditional machine learning algorithms against deep learning architectures on Indonesian culinary datasets.
* **Key Highlights:** Benchmarked **KNN, SVM, and XGBoost** alongside **ResNet50** and **Vision Transformer (ViT)** using 5-fold cross-validation.
* **Tech Stack:** `Python`, `PyTorch / TensorFlow`, `Scikit-learn`, `OpenCV`, `Google Colab`

#### 4. GreenSpace — Plant E-Commerce & Care UI/UX Prototype
A minimalist, user-centered mobile and landing page design concept for an indoor plant marketplace and plant-care assistant.
* **Key Highlights:** Designed clean navigation flows, product discovery cards, and responsive layouts with light/dark mode considerations.
* **Tech Stack:** `Figma`, `UI/UX Prototyping`
